📑 Project Architecture & Deployment Guides

1

S3 Event / Cron

EventBridge triggers Lambda scanner every 5 minutes or on S3 bucket changes.

➡️

Lambda Scanner

Python boto3 checks PublicAccessBlock, Bucket Policy, and ACL Grants.

➡️

AWS IoT Core

➡️
4

ESP32 Red Lamp

Receives MQTT topic over TLS; blinks Red LED rapidly on ALERT state!

// Hardware Wiring Connections
ESP32 GPIO 4  ---> [ 220 Ohm Resistor ] ---> Red LED Anode (+)
ESP32 GND     ---------------------------> Red LED Cathode (-)
